what are core modules?

    Node.js core modules are built-in libraries that come with the Node.js installation and provide essential functionalities for server-side development, such as file system operations, networking, and operating system interaction. They are always available to use without any additional installation via npm. 

    Commonly used core modules include:
        fs (File System): Provides functions for interacting with the file system, enabling file reading, writing, updating, and deleting. It supports both synchronous and asynchronous operations.

        http and https: These modules allow Node.js to create HTTP and HTTPS servers and handle client-server communication. They are fundamental for building web servers and APIs.
